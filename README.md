# mk-styleguide

The shared design system for Kokes Projects: small web apps, developer tools and personal sites. It's built around neon lime on charcoal and white, set in Poppins and Inter.

The colors, type, spacing and rules are defined once here, as design tokens plus an agent-ready guide, so every project (and every AI coding agent working on one) styles things the same way.

## What's here

| File | Use it for |
| --- | --- |
| [`STYLEGUIDE.md`](STYLEGUIDE.md) | The full guide: voice, color roles, palette, contrast results, type scale, spacing, motion, icons, component recipes, accessibility and a code-review checklist. Written for AI agents and humans. |
| [`tokens.css`](tokens.css) | CSS custom properties with light and dark values. Use this in non-Tailwind projects. |
| [`tailwind.css`](tailwind.css) | A Tailwind v4 entry file (`@theme`) with the same tokens. Use this instead of `tokens.css` in Tailwind projects. |
| [`tokens.json`](tokens.json) | W3C Design Tokens (DTCG) for Style Dictionary, Figma plugins and other tooling. |
| [`kokes-projects.styleguide.json`](kokes-projects.styleguide.json) | The editable source. Import it into Styleguide Generator to change the system (see [Updating the system](#updating-the-system)). |

## At a glance

| | Light | Dark |
| --- | --- | --- |
| Background | White `#FFFFFF` | Charcoal `#242424` |
| Text | `#242424` | `#F7F7F7` |
| Muted text | Dim grey `#6E6E6E` | `#C1C1C1` |
| Primary fill (buttons) | Lime `#BAFF39` with `#242424` text | Lime `#BAFF39` with `#242424` text |
| Links, focus rings | Olive `#476700` | Lime `#BAFF39` |

- **Lime is a fill, never text on white.** Lime on white is 1.2:1, which is unreadable. Use it as a button or highlight fill with dark text, or as text on dark backgrounds.
- **Headings** are Poppins (600, 700). **Body and UI** use Inter (400, 500, 600). **Code** is JetBrains Mono (400, 500).
- **Shape:** buttons and tags are pills (`--radius-full`), and cards are `--radius-lg` (16px).
- **Icons:** Lucide, outline, 2px stroke, at 16, 20 or 24px.
- All role pairings meet WCAG 2.2 AA in both modes. See the contrast table in `STYLEGUIDE.md`.

## Using it in a project

### 1. Bring in the files

Copy the files you need into the project, or add this repo as a submodule so updates can be pulled in later:

```bash
git submodule add https://github.com/mkokes/mk-styleguide.git styleguide
```

### 2. Load the fonts

```html
<link rel="preconnect" href="https://fonts.googleapis.com" />
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
<link
  rel="stylesheet"
  href="https://fonts.googleapis.com/css2?family=Poppins:wght@600;700&family=Inter:wght@400;500;600&family=JetBrains+Mono:wght@400;500&display=swap"
/>
```

You can self-host with Fontsource (`@fontsource/poppins`, `@fontsource-variable/inter`, `@fontsource-variable/jetbrains-mono`) instead.

### 3a. Plain CSS

Import `tokens.css` once, globally, then style only with the tokens:

```css
@import "./styleguide/tokens.css";

body {
  background: var(--color-bg);
  color: var(--color-text);
  font-family: var(--font-body);
  font-size: var(--text-base);
}

h1, h2, h3, h4 {
  font-family: var(--font-heading);
}

a {
  color: var(--color-link);
}

.button-primary {
  background: var(--color-primary);
  color: var(--color-on-primary);
  border-radius: var(--radius-full);
  padding: var(--space-2) var(--space-4);
}
```

### 3b. Tailwind v4

Use `tailwind.css` as the CSS entry, in place of `@import "tailwindcss"`. It already imports Tailwind:

```css
@import "./styleguide/tailwind.css";
```

The tokens then work as utilities: `bg-bg`, `bg-surface`, `text-text`, `text-text-muted`, `bg-primary text-on-primary`, `text-link`, `font-heading`, `text-xl`, `rounded-full`, `shadow-sm`, `p-4` and so on.

### Dark mode

Dark values apply when `<html data-theme="dark">` is set. Without the attribute they follow the OS preference, and `data-theme="light"` forces light mode. Role tokens such as `--color-bg`, `--color-text` and `--color-link` switch automatically, so use them for UI rather than raw palette steps like `--color-neutral-900`. In Tailwind, the `dark:` variant follows the same attribute.

### Point your AI agent at the guide

Add a line like this to the project's `CLAUDE.md` or `AGENTS.md`:

```markdown
## Styling

Follow [styleguide/STYLEGUIDE.md](styleguide/STYLEGUIDE.md) for all colors, fonts, spacing, icons and component styling. Use its tokens; never hardcode values a token covers.
```

The guide ends with a code-review checklist that an agent can run against its own changes.

## Updating the system

These files are generated by [Styleguide Generator](https://mkokes.github.io/styleguide-generator/) ([source](https://github.com/mkokes/styleguide-generator)). Edit them there rather than by hand, so the guide and every token format stay in sync:

1. In the generator, choose **Import file** on the home page and pick `kokes-projects.styleguide.json`, or open the guide if it is already saved in your browser.
2. Make your changes. The live preview and contrast checks update as you edit.
3. On **Review & export**, download the files and replace the ones in this repo. Use **Export project file** too, and save it over `kokes-projects.styleguide.json`.
4. In each project that uses the styleguide, pull the update (`git submodule update --remote styleguide`, or copy the files again).
